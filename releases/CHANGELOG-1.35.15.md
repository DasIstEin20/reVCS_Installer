reVCS Manager 1.35.15
Changes since public Manager 1.35.14

- Added Persian localisation support.
- Updated the settings editor to support the new revcs.set format.
- Improved EU/US save compatibility detection and related messages.
- Added music selection for the main menu, loading screens and pause menu.
- Improved texture-pack compatibility, preparation and resource handling.
- Expanded Vice City and PCSX2 texture replacement support.
- Improved installation and update handling while preserving selected languages and texture packs.
- Improved progress reporting and installation workflow.
- Added crash and debug report management and cleanup.
- Updated crash reporting and debug logging options.
- Updated the accompanying tools to version 1.35.15.
- Added support for the Update 9 installation path, retaining the existing Update 8.10 to 8.11 upgrade path.
- Added verification method.
