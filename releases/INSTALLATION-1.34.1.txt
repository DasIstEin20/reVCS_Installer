reVCS Setup 1.34.1 beta

Extract the bootstrap ZIP into a writable folder and run reVCS-Setup-1.34.1.exe.
Keep installer.cfg, version.xml and the tools folder beside the EXE.
Online access is enabled by default. Setup downloads missing BIN components.
For offline use, download all 13 BINs from this release and put them beside Setup.
Use your own VCS PS2 ISO or extracted disc folder and an empty destination.

Existing installation: close Setup, back up its EXE and replace it with the new
EXE (you may keep the installed name reVCS Setup.exe). Keep your installer.cfg
and tools folder. Choose the correct installed folder on Welcome if needed.
No game reinstall or ISO reconversion is required. Existing offline choices stay.

Apply game Update 8.1 from Updates > Check game updates > Apply available game
updates. Use Extended mode for Updates and Advanced > Keep update backups.
The backup choice is saved immediately and applies to future game updates and
runtime repairs. Turning it off removes temporary rollback files after success.
Previous backups are preserved. Game data, settings and saves remain in place.
