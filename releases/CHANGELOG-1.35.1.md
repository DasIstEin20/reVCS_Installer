reVCS Manager 1.35.1

- Add a graphics-backend selector in Launch Options, detecting the installed
  Direct3D 11 and Direct3D 9 executables and selecting their matching architecture.
- Add 72 interface glyphs across navigation, actions and auxiliary windows,
  including the corrected music-folder icon.
- Prefer the game beside Manager when using a portable installation, preventing
  an older remembered installation from being launched by mistake.

Existing preferences, Quick/Extended modes, texture-pack selections and saves
are preserved. The game update is supplied as a separate cumulative package.
