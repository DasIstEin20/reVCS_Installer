reVCS Manager 1.35.16
Changes since public Manager 1.35.15

- Added PS2 save import for raw, PSU, CBS, MAX, NPO, PSV and ZIP files, including slot selection for containers holding multiple saves.
- Added raw PS2 save export for compatible PCSX2 folder memory cards.
- Expanded installation verification and selective repair of missing or modified managed files.
- Added embedded repair metadata as a fallback for supported installations with missing or unreadable manifests.
- Fixed update failures affecting certain older installations.
- Prevented optional language-file issues from blocking game updates while preserving custom translations.
- Added installation and update failure reports, with a Show logs button that opens their diagnostic ZIP location.
- Improved verified download-cache reuse and cache-status messages.
- Improved cleanup of obsolete managed files and introduced stable update-document filenames.
- Corrected architecture and graphics-backend selection to reflect installed variants.
- Unified launch controls into one Play reVCS action that preserves the selected architecture, backend and custom arguments.
- Improved dashboard button layouts and added an overlapping launch-options shortcut to Play reVCS.
- Updated the accompanying Tools component.
