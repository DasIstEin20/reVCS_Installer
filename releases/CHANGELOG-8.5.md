# reVCS Alpha Update 8.5

reVCS 0.55 Alpha Update 8.5

- Extended Streaming adds adaptive, visibility-aware preparation and staged work.
- CPU task preparation, full mip-chain support and optional geometric LOD reduce
  unnecessary work; existing extended settings remain under reVCS Extras.
- Custom map waypoints draw road GPS routes using the native road graph.
- In-game PCSX2 pack overview shows active selected and retained source counts.
- Camera-homing preference, version footer and free-project notice.
- Preserves the cumulative fire-truck, helicopter, stunt-camera, traffic-light,
  forklift, EU/US save compatibility, fonts and character-pack corrections.

Road GPS and the pack overview are new. Change pack selections in Manager and
restart the game. Performance depends on the scene, hardware and chosen packs.
