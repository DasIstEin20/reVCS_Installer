reVCS Setup 1.34.1 beta (refreshed build)

Extract the bootstrap ZIP into a writable folder and run reVCS-Setup-1.34.1.exe.
Keep tools, installer.cfg and version.xml beside Setup. Online access is enabled.
Setup checks for its own updates on every launch, verifies each download, replaces
its EXE and restarts. Disable startup checks or automatic installation in Advanced.
Welcome also provides Check Setup updates. Same-version refreshed builds are
recognized by SHA256. The previous Setup is retained for rollback if startup fails.

Existing users: close Setup, replace its EXE with this refreshed 1.34.1 EXE and
keep installer.cfg and tools. Old 1.34.1 builds require this one-time replacement;
their earlier numeric-only checker cannot identify a same-version refreshed build.
No game reinstall or ISO reconversion is required. Your game settings are preserved.

Game update actions appear after choosing or installing a game. Apply game 8.1
through Updates. Advanced > Keep update backups saves either checkbox state.
Only changed files are staged; turning retained backups off removes temporary
rollback files after success. Download cache is cleaned after use and at startup.
Local package folders and unrecognized files are not removed by cache cleanup.

Offline installation: download the same 13 BIN components from this release,
place them beside Setup and version.xml, then disable online access.
