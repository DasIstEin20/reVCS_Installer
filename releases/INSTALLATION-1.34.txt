reVCS Setup 1.34 beta - installation and release files
For reVCS Alpha 0.55 Update 8, Windows 10 / 11 (64-bit)

QUICK START
1. Download reVCS-Setup-1.34-bootstrap.zip from release v1.34.0-beta.
2. Extract the ZIP into a writable folder. Keep its tools folder beside Setup.
3. Run reVCS-Setup-1.34.exe and select your own PS2 ISO or extracted disc folder.
4. Choose a new or empty destination. Setup obtains and checks missing components.

OFFLINE INSTALLATION
Use the complete local kit: Setup, installer.cfg, version.xml, tools and all
13 reVCS-*-1.34.0.bin files. Keep them together or select the package folder in
Setup. Switch online access off before installing and select your local PS2 ISO
or extracted disc folder.

INTEGRITY
Compare downloaded files with SHA256SUMS-1.34.txt. Setup also checks component
sizes and SHA256 hashes automatically before using them.
For a downloaded file, Windows PowerShell can show its SHA256 with:
  Get-FileHash -LiteralPath '.\reVCS-Setup-1.34-bootstrap.zip' -Algorithm SHA256

installer.cfg is user-editable. Once Setup saves personal preferences, its hash
can differ from the original distribution file. The unchanged bootstrap ZIP
contains the original defaults; retain personal settings while checking them.

UPDATES
The editable installer feed is:
https://raw.githubusercontent.com/DasIstEin20/reVCS_Installer/main/manifests/version.xml
Default retired project Archive.org channels migrate to that address. Custom
mirrors and offline preferences are preserved. Installer self-replacement is
disabled by default. Download a new Setup manually when you want to upgrade it.

Setup 1.34 updates the interface and downloads. The included game version is
reVCS Alpha 0.55 Update 8. Both Setup and the game are still in development.
Optional PCSX2 texture packs remain user-supplied. No PS2 disc image is included.
